This is the repo for the QUBO Simulated Annealing Optimizer. 

I use System Verilog V13 on MSYS2 for the implementation, and I run the test bench on VS-Code.

I have also added a python implementation so that you can see how the algorithm works sequentially.

The version in the repo is the 30 x 30 Q matrix solver with a local minimum check at the end. The brute force comparison is not here.
